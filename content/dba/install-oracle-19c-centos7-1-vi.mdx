# Đối tượng
Đây là bài viết hướng dẫn cơ bản các công việc để cài đặt thành công Oracle Database 19c trên môi trường hệ điều hành Oracle Linux 7. Phiên bản cơ sở dữ liệu được chọn là phiên bản cơ sở 19.3.0.0.0 và hệ điều hành Oracle Linux 7.9.
Cơ sở dữ liệu sẽ sử dụng File System để lưu trữ các file dữ liệu.

# Chuẩn bị
- Server cài đặt thành công hệ điều hành Oracle Linux 7.9 (File ISO: OracleLinux-R7-U9-Server-x86_64-dvd.iso [4.7GB] https://yum.oracle.com/oracle-linux-isos.html#content-1)
- Bộ cài bao gồm các file
-- oracle-database-preinstall-19c-1.0-1.el7.x86_64.rpm : File rpm preinstall (https://yum.oracle.com/repo/OracleLinux/OL7/latest/x86_64/getPackage/oracle-database-preinstall-19c-1.0-1.el7.x86_64.rpm)
-- V982063-01.zip : File cài đặt tải từ Oracle edelivery https://edelivery.oracle.com Oracle Database 19.3.0.0.0 Part V982063-01.
