Đây là minh họa các thành phần cơ bản của cơ sở dữ liệu Oracle. Cơ sở dữ liệu Oracle gồm các thành phần cơ bản sau:

1. **Oracle Software**: Là các file cài đặt của cơ sở dữ liệu Oracle. Chúng nằm tại folder biến môi trường ORACLE\_HOME. Chúng còn bao gồm các công cụ và script phục vụ hoạt động của cơ sở dữ liệu Oracle và hỗ trợ quản trị cơ sở dữ liệu. Nổi bật bao gồm SQL\*Plus, RMAN và AWR scripts.
2. **Database**: Là các file vật lý lưu trữ trên ổ cứng. Chúng được chia vào các nhóm với chức năng khác nhau:
   * **Data Files**: Các file chứa dữ liệu hệ thống và người dùng.
   * **Control Files**: Các file chứa dữ liệu cấu trúc của cơ sở dữ liệu.
   * **Online Redo Log Files**: Các file chứa thay đổi của cơ sở dữ liệu.
3. **Oracle Instance**: Đây là các tiến trình chạy và vùng bộ nhớ được sử dụng khi cơ sở dữ liệu hoạt động. Chúng được chia vào 3 nhóm chính:
   * **Background Processes**: Các tiến trình nền phục vụ hoạt động của cơ sở dữ liệu
   * **SGA:** Vùng bộ nhớ dùng chung cho các tiến trình của cơ sở dữ liệu
   * **Server Processes**: Các tiến trình phục vụ truy cập của người dùng (mỗi tiến trình có vùng bộ nhớ PGA riêng)
4. **Oracle Net**: Đây là lớp tiến trình thực hiện quản lý kết nối giữa cơ sở dữ liệu và các ứng dụng của người dùng thông qua mạng.
5. **Other Files**: Đây là các file chứa các cấu hình, nhật ký hoạt động và sao lưu. Chúng bao gồm:
   * **Parameter Files**: Các file chứa tham số hoạt động của Oracle Instance.
   * **Password File**: File chứa mật khẩu của tài khoản người dùng quản trị.
   * **Diagnostic Files**: Các file chứa log cảnh báo, log lỗi, log theo dõi và ghi nhật ký lỗi, log xác thực truy cập.
   * **Backup Directory**: Folder chứa các file archive log, file backup và file dump của cơ sở dữ liệu.

Cảm ơn bạn đã theo dõi bài viết này!
